# Classic Snake

A minimal browser-based Snake game.

## Run locally

1. Start a static server:
   ```bash
   npm start
   ```
2. Open `http://localhost:4173`.

## Run tests

```bash
npm test
```

## Manual verification checklist

- [ ] Arrow keys and WASD move the snake.
- [ ] Space or Pause button toggles pause/resume.
- [ ] Snake grows and score increments after eating food.
- [ ] Hitting a wall or itself ends the game.
- [ ] Restart button (or Enter after game over) resets state.
